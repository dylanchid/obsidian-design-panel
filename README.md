# Design Panel

Live design sidebar — type, scale, color, and layout with real-time preview

## Use

Open **Design Panel** from the ribbon or command palette. Adjust type, scale, color, and layout while viewing the live preview. The command **Copy Design Panel CSS** copies the current styling for reuse. The panel includes Reading, Compact, Editorial, and Dev notes presets.

## Install manually

Run `npm ci && npm run build`, then copy `manifest.json`, `main.js`, and `styles.css` into `<vault>/.obsidian/plugins/design-panel/`. Enable the plugin under **Settings → Community plugins**.

## Develop

Run `npm ci` and `npm run build` from this directory.
